# 📝 BlogSpace — Responsive Blog Application

BlogSpace is a responsive frontend blog application built using HTML, CSS, and JavaScript. It allows users to register, log in, create blogs, manage their posts, and read articles through a clean and responsive interface.

## 🚀 Features

- Responsive modern user interface
- User registration
- User login
- Form validation
- LocalStorage-based authentication
- Protected dashboard
- Create and publish blogs
- Blog categories
- Optional blog cover images
- Dynamic blog rendering
- Personal dashboard
- Delete blog functionality
- Blog counter
- Individual blog reading page
- Logout functionality
- Mobile responsive navigation

## 🛠️ Technologies Used

## 💻 How to Run the Project

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Register a new account.
5. Login using your registered credentials.
6. Create and manage blogs from the dashboard.

## 🔐 Authentication

This project uses browser LocalStorage to demonstrate frontend authentication and data persistence.

For a production application, authentication and passwords should be handled securely using a backend and database.
